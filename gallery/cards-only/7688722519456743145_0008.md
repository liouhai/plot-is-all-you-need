**评价**：每个特征一幅卡片，散点沿着一条金色平滑曲线排开，点的颜色就是自己的取值，所以颜色从蓝渐变到红，和横轴方向同步，读者看颜色就知道在读哪一段。红点标出曲线和零线的交点，旁边写具体取值，等于把“从哪个取值开始由负变正”这个结论标在图里了。曲线很干净，没有置信带和直方图，适合特征多、想让每幅尽量简洁的场合。

**部件亮点**
- 结构布局：3×3 九幅小卡片，右侧一条竖直色条，顶部通栏图例框
- 图形元素：小圆点贴着金色曲线，红色大圆点加竖虚线标过零点，灰色水平虚线是零线
- 配色：蓝到白到深红的发散色，金色曲线，红点鲜艳
- 文字与标注：每幅顶部一个标题框写特征名，红点旁写取值，纵轴写 SHAP Value
- 装饰细节：圆角卡片带淡阴影，外圈虚线框
- 图例与色条：顶部通栏图例，右侧竖直色条标 Feature Value 的 Low、Mid、High
